# Code of conduct

Be decent. This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):

- Assume good intent and ask questions before assuming malice.
- Critique code and ideas, never people.
- No harassment, discrimination, or personal attacks — in issues, PRs, reviews or releases.
- Respect the maintainer's scope decisions: this plugin deliberately stays small and Host-free.

Violations can be reported privately to the maintainer (see `package.json` / `SECURITY.md`).
Maintainers may edit or remove comments, close threads, or block accounts that break these rules.
